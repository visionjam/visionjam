### Hi, I'm VisionJam

A university student in China, not a CS major — I code out of interest, not for coursework.

- ✍️ Blogging with **Hugo + PaperMod**; every post stays as Markdown in my own repo.
- 📱 Tinkering with **Android**: settings, privacy, background and battery. If a tool is abandoned, I rewrite it.
- 🐍 Using **Python** to kill repetitive work: documents, media archiving, environment rebuilds.
- 🗄️ Into **digital minimalism and privacy**: self-host when possible, keep data local when possible.

**Selected projects**

- [imagefolder-open](https://github.com/visionjam/imagefolder-open) — an Android app that hides any file inside PNG / JPEG / WebP images; an independent rewrite of the discontinued Image Folder. *Kotlin · Compose*
- [zhihu-archive](https://github.com/visionjam/zhihu-archive) — a full archive site for my Zhihu answers, posts and articles; images localized, cookies never leave the machine. *Python · Hugo*
- [cue-image-to-flac-toolkit](https://github.com/visionjam/cue-image-to-flac-toolkit) — CUE + image → per-track FLAC, with sample-accurate splitting and per-track PCM MD5 proofs. *Python · ffmpeg*
- [physics-lab-report-tools](https://github.com/visionjam/physics-lab-report-tools) — a .docx toolkit for university physics lab reports: formatting, LaTeX → OMML, data plotting. *Python*
- [seedbox-setup](https://github.com/visionjam/seedbox-setup) — a minimal BitTorrent seedbox stack on a public VPS. *Shell · Docker*
- [linux-workstation-setup](https://github.com/visionjam/linux-workstation-setup) — everything needed to rebuild my Ubuntu workstation, pitfalls included. *Shell*
- [obsidian-visionjam-theme](https://github.com/visionjam/obsidian-visionjam-theme) — a purple-accented Obsidian dashboard: 9 CSS snippets and 11 Templater templates. *CSS*
